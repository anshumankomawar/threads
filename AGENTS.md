# ui-sdk

The interface is built with ui-sdk (`@ui-sdk/react`, `@ui-sdk/core`). Before using it, follow the ui-sdk skill if it's
installed (`.claude/skills/ui-sdk`), and read `node_modules/@ui-sdk/react/docs/llms.txt`. To build a new component,
also search `node_modules/@ui-sdk/react/docs/core.md` by heading, and read `rendering.md` next to it.
